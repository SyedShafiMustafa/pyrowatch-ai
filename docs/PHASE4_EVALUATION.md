# Phase 4 evaluation status

**Real-world wildfire accuracy: NOT VERIFIED.** The repository contains a
labelled synthetic sample generated by `scripts/make_synthetic.py`. Its planted
labels are a software fixture and reflect the generator's brightness, FRP,
confidence and location choices. They cannot independently validate the
heuristic or anomaly model. No genuine, provenance-documented FIRMS CSV with
credible fire labels was available for this phase.

The existing `compare` result retains heuristic, FRP-only, newest-first and
confidence-only precision-at-k checks and prevalence as `random_baseline`.
Phase 4 adds a seeded random ordering check. These are descriptive checks on the
supplied labels, not held-out accuracy claims. The API reports them on the
synthetic sample as pipeline evidence only.

`split_event_holdout` reserves the latest whole event groups for testing, so a
related event cannot appear in both partitions. `evaluate_heldout_rankings`
compares heuristic, peak-FRP, newest-first and seeded random rankings on an
already held-out event table. It reports average precision (a PR-summary
metric), precision@k, recall@k and F1@k. It can also report an anomaly-only
ranking when a separate model reference ID set is supplied and disjoint from
the test IDs. No heuristic/anomaly combined ranking is enabled. The caller must
use stable source event identifiers, document label provenance, train every
preprocessor and model on the training side only, and check temporal/geographic
independence. Response-local `event_id` values alone cannot prove independence
across uploads. The helper does not fit a model or certify labels.

If a credible labelled dataset becomes available, record source and review
method, split complete events by time and geography, fit on the training side,
then evaluate the untouched holdout with class prevalence and uncertainty
intervals. A synthetic anomaly distribution or a successful API test cannot
replace that evaluation. Cloud gaps, sensor differences and persistent heat
sources should be represented in failure-case review before operational claims.
